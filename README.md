## 🚀 Featured Projects

### 🏥 [NPPES Provider Data Pipeline](https://github.com/ByungkyuKang/nppes-provider-pipeline)

**Python | pandas | DuckDB | Docker | ETL**

An ETL pipeline for processing CMS NPPES healthcare provider data.

- Processed a weekly incremental dataset containing **32,691 rows and 330 source columns**.
- Implemented CSV ingestion, NPI-based deduplication, data normalization, and provider deactivation status derivation.
- Added data quality checks for missing or duplicate NPIs and invalid entity type codes.
- Built idempotent DuckDB loading to prevent duplicate records across repeated runs.
- Scheduled daily pipeline runs using Windows Task Scheduler and configured Docker execution with persistent storage.
